GIT AND GIT HUB

git init
git config --global user.name "Your Name"
git config --global user.email "your.email@example.com"

git add . or git add file name
git commit -m "first commit"
git branch -M main
git remote add origin https://github.com/bhoomika1812/FSD-BACKEND-CSE-16.git
git push -u origin main

git status
git log      // no of commit
git branch
git clone url

git push or git push origin

If you work from another computer too, always start with:
git pull origin main
before making changes. This keeps both computers synchronized and avoids branch
divergence.
